# Music Player

Interactive keyboard-controlled audio player built with Pygame.

## Playlist
- haggstrom.mp3
- MEGALOVANIA.mp3
## Controls
- `P` — Play
- `Space` — Pause / Resume
- `S` — Stop
- `X` — Rewind 5 seconds (-5s)
- `C` — Forward 5 seconds (+5s)
- `N` — Next track
- `B` — Previous track (Back)
- `Q` / `ESC` — Quit
